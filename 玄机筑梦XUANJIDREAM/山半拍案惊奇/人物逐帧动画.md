# 正面
基于参考图保持人物样貌、服装、发型完全一致，
（填入微动部位1，如：肩线随呼吸极轻起伏），
（填入微动部位2，如：发梢随风微微飘动），
（填入微动部位3，如：睫毛缓慢眨动，嘴角保持微笑），
（填入运镜，如：固定镜头 / 镜头极缓推近），
画面稳定流畅，无抖动无闪烁，面部清晰不变形，
人体结构正常，4K高清，电影质感。

# 负面
画面变形，人物畸形，五官错乱，手指畸形，肢体异常，
动作僵硬，画面卡顿，画质模糊，低分辨率，水印，
文字，抖动，穿模，杂乱，大幅度动作

# ps
1. 动作写“慢、轻、连续”——用“极轻起伏”“微微飘动”“缓慢眨动”这类词，避免“跑、跳、挥、打”等剧烈动词。
2. 一个镜头只写 1–2 个微动部位——比如“呼吸+眨眼”就够了，别同时塞“呼吸+眨眼+撩发+转身”，AI 会顾此失彼。
3. 首帧思维——图生视频时，提示词要描述“从参考图出发的微小连续变化”，而不是笼统写“让人物动起来”，否则容易变脸。

- 即梦单次生成的是 3–5 秒的线性片段，要变成真正的“循环动画”，需要在剪辑软件里处理：
1. 剪映操作：将生成的视频导入 → 复制一份接在后面 → 对第二段加倒放​ → 两段中间加 0.1–0.2 秒叠化转场，就能实现无缝循环。
2. 更进阶：用即梦的首尾帧功能——上传同一张人物图作为首帧和尾帧，提示词写微动描述，生成出来的视频首尾天然接近，循环更顺滑。
